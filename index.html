Logistic Regression Visualizer

Logistic Regression is a classification algorithm that predicts the probability of an input belonging to a class. Adjust the data and watch the model learn a decision boundary through gradient descent.

💡 How it works?

  1. Calculate z = w₁x₁ + w₂x₂ + b
  2. Convert z to probability using sigmoid
  3. Compare prediction with actual class
  4. Calculate loss
  5. Update weights using gradient descent
  6. Repeat until convergence
